# NeoQM — Releases

Installers and update manifests for **NeoQM**, a modern linear programming tool (graphical and simplex methods).

## Download

Get the latest version from [Releases](https://github.com/Nightmare33n/NeoQM-releases/releases/latest):

- `NeoQM_x.y.z_x64-setup.exe` — recommended installer (per-user, no admin rights)
- `NeoQM_x.y.z_x64_en-US.msi` — MSI package

The app updates itself from this repository. Every update is signed and verified before it is installed.

> Windows SmartScreen may warn on first install because the installer is not Authenticode-signed. Choose **More info → Run anyway**.
